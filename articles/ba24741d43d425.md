# 概要

今回はJetpack Media3で簡単なmp3の再生、速度変更をCompose内で扱うような実装を試してみました。

## Jetpack Media3とは

https://developer.android.com/media/media3?hl=ja

> ExoPlayerを含むメディア再生のサポートライブラリ集
動画ファイルと音声ファイルの再生に関する基本的な機能を定義する **`Player`** インターフェースを定義します。**`ExoPlayer`** は、Media3 におけるこのインターフェースのデフォルト実装です

以前からある[ExoPlayer](https://github.com/google/ExoPlayer)がJetpackに統合され、今後の更新・周辺機能（Session/UI等）も含めてJetpack Media3 となっています。

Jetpack Media3には以下のコンポーネントが存在します。

- **メディア プレーヤー (`media3-exoplayer`)**
  - プレイヤー本体
  - `Player`インターフェースを実装したものが**`ExoPlayer`**
  - 再生/一時停止/シーク等を担当
  - プロトコル/形式を拡張できる
    - `media3-exoplayer-hls`
    - `media3-exoplayer-dash`
    - `media3-exoplayer-smoothstreaming`
    - `media3-exoplayer-rtsp`
- **メディア セッション (`media3-session`)**
  - メディア プレーヤーを操作するための汎用的な手段を提供
  - 外部ソースから再生制御リクエストを受信できるようになる
- **UI コンポーネント (`media3-ui`)**
  - **`media3-ui`**：ViewベースのUI（PlayerView等）
  - **`media3-ui-compose`**：Compose版UI
- **編集・変換 (`media3-transformer`)**
  - **`media3-transformer`**：トリミング・結合・変換などの編集系API
  - **`media3-effect`**：Transformerで使うエフェクト系
- **データ取得・解析 (`media3-datasource`)**
  - **`media3-datasource`**：データ取得の土台（ローカル/ネット等）
  - **`media3-datasource-okhttp` / `media3-datasource-cronet`**：HTTPスタックを差し替えたい時の追加
  - **`media3-extractor`**：コンテナ（mp3/mp4等）から音声・映像トラックを取り出す
  - **`media3-decoder`**：追加デコーダ系
- **共通 (`media3-common`)**
  - 共通型やユーティリティ

# 最低限の実装

まずは、一番シンプルで最低限のものしかない実装を試してみたいと思います。作るものはリソースファイルとして設置したmp3ファイルを再生するだけのものを作ります。早速新規にAndroid Studioでプロジェクトを作成していきます。

今回は「New Project」>「Empty Activity」で以下内容で作成しました。

![image1.png](/images/ba24741d43d425/image1.png)

## ライブラリ追加

必要なライブラリを `gradle/libs.versions.toml` に追記していきます。ExoPlayer本体とUIは `media3-ui-compose-material3` を使います。

```toml
[versions]
media3 = "1.9.0"

[libraries]
media3-exoplayer = { group = "androidx.media3", name = "media3-exoplayer", version.ref = "media3" }
media3-ui = { group = "androidx.media3", name = "media3-ui-compose-material3", version.ref = "media3" }
```

※ Media3 1.9.0 は minSdk 23 です（古いminSdkのプロジェクトは注意）

次に `app/build.gradle.kts` に以下を追加します。

```kotlin
dependencies {
    // ....
    implementation(libs.media3.exoplayer)
    implementation(libs.media3.ui)
}
```

## 音源を設置

`app/src/main/res/raw` に音源を追加します。今回は以下サイトの6秒のmp3音源を使わせて頂きました。

https://samplelib.com/sample-mp3.html

ダウンロードしたものを `app/src/main/res/raw/sample.mp3` に設置します。

※ ビルド時に以下の様なエラーが出る場合はファイル名に使えない文字(👇の場合だと `-` )が含まれています。

```text
'-' is not a valid file-based resource name character: File-based resource names must contain only lowercase a-z, 0-9, or underscore
```

## 実装

`MainActivity` を以下の様に変更します。

```kotlin
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            TryJetpackMedia3Theme {
                Scaffold(modifier = Modifier.fillMaxSize()) { innerPadding ->
                    MainPlayer(
                        modifier = Modifier.fillMaxSize().padding(innerPadding)
                    )
                }
            }
        }
    }
}

@Composable
fun MainPlayer(modifier: Modifier = Modifier) {
    val context = LocalContext.current
    val lifecycleOwner = LocalLifecycleOwner.current

    val player = remember {
        ExoPlayer.Builder(context).build().apply {
            val uri = "android.resource://${context.packageName}/${R.raw.sample}".toUri()
            setMediaItem(MediaItem.fromUri(uri))
            prepare()
            playWhenReady = true
        }
    }

    Column(
        modifier = modifier,
        verticalArrangement = Arrangement.Center,
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        // 再生位置 + 総時間
        PositionAndDurationText(player)

        // コントロールボタンを設置
        Row(horizontalArrangement = Arrangement.spacedBy(12.dp)) {
            SeekBackButton(player)
            PlayPauseButton(player)
            SeekForwardButton(player)
        }
    }
}
```

これを実行すると起動時に音源が再生され、以下の様な画面が表示されます。

## バックグラウンドになったら停止する

次はアプリがバックグラウンドになったら停止し、アプリ終了時は `player` の終了処理を行うようにしたいと思います。

先ほどの `MainPlayer` に以下を追加します。

```kotlin
@Composable
fun MainPlayer(modifier: Modifier = Modifier) {
    // 追加
    val lifecycleOwner = LocalLifecycleOwner.current

    // 追加
    DisposableEffect(lifecycleOwner, player) {
        val observer = LifecycleEventObserver { _, event ->
            when (event) {
                Lifecycle.Event.ON_STOP -> player.pause()
                Lifecycle.Event.ON_DESTROY -> player.release()
                else -> Unit
            }
        }
        lifecycleOwner.lifecycle.addObserver(observer)
        onDispose {
            lifecycleOwner.lifecycle.removeObserver(observer)
        }
    }
}
```

**[DisposableEffect](https://developer.android.com/reference/kotlin/androidx/compose/runtime/package-summary#DisposableEffect(kotlin.Any,kotlin.Function1))** で **[LifecycleObserver](https://developer.android.com/reference/androidx/lifecycle/LifecycleObserver?hl=ja)** を使用してアプリのライフサイクルに応じて `player` の停止や終了処理を行なっています。

これで実際にアプリがバックグラウンドになったら再生が停止されるかと思います。

# 再生速度を変更できる様にする

次に再生されている音源の再生速度を変更できる様にしてみたいと思います。まずは確認しやすくする為にループ再生されるようにします。

`player` を作成している箇所で `repeatMode` を `REPEAT_MODE_ONE` に設定します。

```kotlin
    val player = remember {
        ExoPlayer.Builder(context).build().apply {
            val uri = "android.resource://${context.packageName}/${R.raw.sample}".toUri()
            setMediaItem(MediaItem.fromUri(uri))
            repeatMode = REPEAT_MODE_ONE // 追加
            prepare()
            playWhenReady = true
        }
    }
```

これで停止しない限りは再生され続けるかと思います。

最後にスライダーを設置し、**[PlaybackParameters](https://developer.android.com/reference/kotlin/androidx/media3/common/PlaybackParameters)** を使用し速度を変更します。

```kotlin
@Composable
fun MainPlayer(modifier: Modifier = Modifier) {
    // ...
    // 追加
    val minSpeed = 0.5f
    val maxSpeed = 2.0f
    var speed by remember { mutableFloatStateOf(1.0f) }

    Column(
        modifier = modifier,
        verticalArrangement = Arrangement.Center,
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        // ...
        // 追加
        Text(text = "速度: ${"%.2f".format(speed)}x  (min=$minSpeed / max=$maxSpeed)")

        // スライダー（動かしている間も即反映）
        Slider(
            modifier = Modifier.padding(all = 12.dp),
            value = speed,
            onValueChange = { newValue ->
                speed = newValue.coerceIn(minSpeed, maxSpeed)
                player.playbackParameters = PlaybackParameters(speed)
            },
            valueRange = minSpeed..maxSpeed
        )
    }
}
```

これを実行すると以下の様にスライダーで速度を `0.5 ~ 2.0` の間で変更できるようになるかと思います。
