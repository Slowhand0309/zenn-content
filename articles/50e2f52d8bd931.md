## async

https://pub.dev/packages/async

> 非同期処理を扱うために、dart:async スタイルに準拠したユーティリティクラス
執筆時のバージョン: **2.13.0**

- 主なユーティリティ
  - [AsyncCache](https://pub.dev/documentation/async/latest/async/AsyncCache-class.html)
    - 時間のかかる非同期計算の結果を一定期間キャッシュしてくれる

      ```dart
      import 'package:async/async.dart' as async;
      
      Future<void> demoAsyncCache() async {
        var counter = 0;
        final cache = async.AsyncCache<int>(const Duration(seconds: 2));
      
        Future<int> load() async {
          counter++;
          print('  expensive computation... (#$counter)');
          await Future<void>.delayed(const Duration(milliseconds: 100));
          return counter;
        }
      
        final v1 = await cache.fetch(load);
        final v2 = await cache.fetch(load);
      
        print('  v1=$v1, v2=$v2 (キャッシュされているので counter=1 のまま)');
      
        // キャッシュの有効期限切れ後
        await Future<void>.delayed(const Duration(seconds: 3));
        final v3 = await cache.fetch(load);
        print('  v3=$v3 (有効期限切れ後なので再計算)');
      }
      /* 実行結果
        expensive computation... (#1)
        v1=1, v2=1 (キャッシュされているので counter=1 のまま)
        expensive computation... (#2)
        v3=2 (有効期限切れ後なので再計算)
      */
      ```

  - [AsyncMemoizer](https://pub.dev/documentation/async/latest/async/AsyncMemoizer-class.html)
    - 非同期操作をメモ化してくれる

      ```dart
      import 'package:async/async.dart' as async;
      
      Future<void> demoAsyncMemoizer() async {
        final memoizer = async.AsyncMemoizer<String>();
      
        Future<String> loadConfig() => memoizer.runOnce(() async {
          print('  実際のロードは一回だけ');
          await Future<void>.delayed(const Duration(milliseconds: 100));
          return 'CONFIG-${DateTime.now().millisecondsSinceEpoch}';
        });
      
        final c1 = await loadConfig();
        final c2 = await loadConfig();
      
        print('  c1=$c1');
        print('  c2=$c2 (同じ値・2回目は中の処理は走らない)');
      }
      /* 実行結果
        実際のロードは一回だけ
        c1=CONFIG-1765349468315
        c2=CONFIG-1765349468315 (同じ値・2回目は中の処理は走らない)
      */
      ```

  - [FutureGroup](https://pub.dev/documentation/async/latest/async/FutureGroup-class.html)
    - 一連の futures が完了するまで待機してくれる

      ```dart
      import 'package:async/async.dart' as async;
      
      Future<void> demoFutureGroup() async {
        final group = async.FutureGroup<String>();
        Future<String> fetchUser() async {
          await Future<void>.delayed(const Duration(milliseconds: 300));
          return 'User';
        }
        Future<String> fetchPosts() async {
          await Future<void>.delayed(const Duration(milliseconds: 500));
          return 'Posts';
        }
      
        group.add(fetchUser());
        group.add(fetchPosts());
        // もう追加しないことを宣言
        group.close();
      
        final results = await group.future;
        print('  FutureGroup results=$results');
      }
      /* 実行結果
        FutureGroup results=[User, Posts]
      */
      ```

    - 他にもStream系のユーティリティが多々あります

## boolean_selector

https://pub.dev/packages/boolean_selector

> 簡略化された Dart 風の文法で書かれたブール式を扱うためのライブラリ。
> セレクターには、識別子、括弧、および ||, &&, !, ?: などのブール演算子を含めることができます。有効な Dart 識別子はすべて許可されており、識別子にはハイフンを含めることもできます。例) `chrome`, `chrome || content-shell` ,`js || (vm && linux)`
> 執筆時のバージョン: **2.1.2**

- サンプル

  ```dart
  import 'package:boolean_selector/boolean_selector.dart';
  
  void main(List<String> args) {
    var selector = BooleanSelector.parse("(x && y) || z");
    print(selector.evaluate((variable) => args.contains(variable)));
  }
  ```

  - `BooleanSelector.parse` で文字列を解析し `evaluate()` で評価する

- どこで使われているか?
  - Dart の `test` パッケージの **platform selector** で、この `boolean_selector` の構文が使われている

    ```dart
    @TestOn('vm && !chrome')
    void main() {
      // このテストは Dart VM かつ Chrome ではない環境でのみ実行
    }
    ```

    - ここの `'vm && !chrome'` 文字列が、内部的には `boolean_selector` の構文としてパース・評価される

## characters

https://pub.dev/packages/characters

> 文字列を、ユーザーが認識する文字の連なりとして扱う事ができるパッケージ
執筆時のバージョン: **1.4.1**

Dart の String は UTF-16 のコードユニット列なので、絵文字や濁点つきの文字などを`substring` や `length` で扱うと文字の途中でバラバラにしてしまう事があります。

```dart
void main() {
  // 「か」+「濁点」 
  final text = 'が';

  print('text: $text');
  print('code unit length: ${text.length}');

  final firstUnit = text.substring(0, 1);
  final secondUnit = text.substring(1, 2);

  print('first unit: $firstUnit');   // 「か」だけ
  print('second unit: $secondUnit'); // 濁点だけ（表示されない or 変な位置に出る）
}
/* 実行結果
text: が
code unit length: 2
first unit: か
second unit: ゙
*/
```

上記を実行すると文字が分解されてしまいます。 `characters` を使うと以下のように1文字として扱うことができます。

```dart
import 'package:characters/characters.dart';

void main() {
  final text = 'が';
  final chars = text.characters;

  print('grapheme length: ${chars.length}');
  print('first grapheme: "${chars.first}"');

  // 先頭1文字を切り出す
  final firstGraphemeOnly = text.characters.take(1).toString();
  print('take(1) as grapheme: "$firstGraphemeOnly"');
}
/* 実行結果
grapheme length: 1
first grapheme: "が"
take(1) as grapheme: "が"
*/
```

## pool

https://pub.dev/packages/pool

> poolパッケージは、限られたリソースのプールを簡単に管理するためのPoolクラスを提供します。
執筆時のバージョン: **1.5.2**

各ユーティリティ

- `Pool`クラス
  - `Pool(this._maxAllocatedResources, {Duration? timeout})`
    - `_maxAllocatedResources`: 一度に割り当てることができるリソースの最大数
    - `timeout` : 設定されている場合、指定された時間が経過しても何も操作が行われなければ、保留中のすべての `future` は `TimeoutException` をスローする
  - 使用例
    - `final pool = new Pool(10, timeout: new Duration(seconds: 30));`
    - 一度に10個のリソースしか割り当てないプールを作成、全てのリソースがチェックアウトされた状態で30秒間操作がない場合エラーを発生させる
- `withResource`
  - コールバックの前にPoolのリソースを確保し、終了後に自動で `release` してくれる

    ```dart
    Future<void> demoWithResource() async {
      final pool = Pool(2); // 同時に最大 2 つまで
    
      Future<void> heavyTask(int id) async {
        print('  [start ] task $id');
        await Future<void>.delayed(const Duration(seconds: 1));
        print('  [finish] task $id');
      }
    
      // Pool.withResource は「このコールバックの間だけリソースを借りる」という意味
      pool.withResource(() => heavyTask(1));
      pool.withResource(() => heavyTask(2));
      pool.withResource(() => heavyTask(3));
    
      await pool.close();
    }
    /* 実行結果
      [start ] task 1
      [start ] task 2
      [finish] task 1
      [start ] task 3
      [finish] task 2
      [finish] task 3
    */
    ```

## shelf

https://pub.dev/packages/shelf

> Shelfは、Webサーバーやその一部を簡単に作成・構成できるようにするツールです。
執筆時のバージョン: **1.4.2**

Dart の HTTP サーバを「Handler」と「Middleware」で組み立てるための軽量フレームワークで、 `Request -> Future<Response>` 関数を積み重ねていくだけなので、挙動が理解しやすいです。

- Echo Serverのサンプル

  ```dart
  import 'package:shelf/shelf.dart';
  import 'package:shelf/shelf_io.dart' as shelf_io;
  
  void main() async {
    var handler =
        const Pipeline().addMiddleware(logRequests()).addHandler(_echoRequest);
  
    var server = await shelf_io.serve(handler, 'localhost', 8080);
  
    // Enable content compression
    server.autoCompress = true;
  
    print('Serving at http://${server.address.host}:${server.port}');
  }
  
  Response _echoRequest(Request request) =>
      Response.ok('Request for "${request.headers}"');
  ```

  上記を実行してアクセスすると以下の様になります。

  ```bash
  $ curl http://localhost:8080
  Request for "{user-agent: curl/8.7.1, accept: */*, host: localhost:8080}"
  ```

- Routing + JSON + POST Bodyサンプル

  ```tsx
  import 'dart:convert';
  
  import 'package:shelf/shelf.dart';
  import 'package:shelf/shelf_io.dart' as shelf_io;
  
  void main() async {
    var handler = const Pipeline()
        .addMiddleware(logRequests())
        .addHandler(_router);
  
    var server = await shelf_io.serve(handler, 'localhost', 8080);
  
    // Enable content compression
    server.autoCompress = true;
  
    print('Serving at http://${server.address.host}:${server.port}');
  }
  
  Future<Response> _router(Request request) async {
    final path = request.url.path;
    final method = request.method;
  
    // GET /
    if (path.isEmpty && method == 'GET') {
      return Response.ok('Hello Shelf!');
    }
  
    // GET /json
    if (path == 'json' && method == 'GET') {
      final body = jsonEncode({
        'message': 'Hello JSON',
        'time': DateTime.now().toIso8601String(),
      });
      return Response.ok(
        body,
        headers: {'content-type': 'application/json; charset=utf-8'},
      );
    }
  
    // POST /echo (ボディをそのまま返す)
    if (path == 'echo' && method == 'POST') {
      final body = await request.readAsString();
      return Response.ok('you posted: $body');
    }
  
    // その他は 404
    return Response.notFound('Not Found');
  }
  ```

  実際のアクセス結果がこちら

  ```bash
  $ curl http://localhost:8080
  Hello Shelf!
  $ curl http://localhost:8080/json
  {"message":"Hello JSON","time":"2025-12-15T21:11:06.678950"}
  $ curl -X POST -d "Hello from curl" localhost:8080/echo
  you posted: Hello from curl
  ```

## stack_trace

https://pub.dev/packages/stack_trace

> このライブラリは、Dart実装によって生成されたスタックトレースの解析、検査、操作を可能にします。また、ネイティブのStackTrace実装よりも読みやすい形式でスタックトレースの文字列表現を生成する関数も提供します
執筆時のバージョン: **1.12.1**

サンプルのプロジェクトを作成して試してみます。

```bash
dart create stack_trace_example
```

- 未使用時のStackTrace
  - ソースコード (bin/stack_trace_example.dart)

    ```dart
    import 'dart:async';
    
    void main() {
      _scheduleAsync();
    }
    
    void _scheduleAsync() {
      Future.delayed(Duration(seconds: 1)).then((_) => _runAsync());
    }
    
    void _runAsync() {
      throw 'oh no!';
    }
    ```

  - 出力

    ```bash
    $ dart run
    ```

## retry

https://pub.dev/packages/retry

> このパッケージは、非同期関数のリトライを簡単に行う方法を提供します。これは、接続の切断や一時的なサーバの過負荷など、断続的に発生するエラーによるクラッシュを回避するのに役立ちます。
執筆時のバージョン: **3.1.2**

「**Exponential Backoff**」(再試行（リトライ）までの待機時間を「1秒、2秒、4秒、8秒…」のように指数関数的に増やしていく)を伴うリトライ処理はシンプルに以下の様に書けます。

```dart
Future<void> demoSimpleRetry() async {
  final random = Random();
  var callCount = 0;
  final result = await retry<String>(
    () async {
      callCount++;
      print('  try #$callCount');
      await Future<void>.delayed(const Duration(milliseconds: 200));
      if (random.nextBool()) {
        throw TimeoutException('temporary timeout');
      }
      return 'success!';
    },
    retryIf: (e) => e is TimeoutException, // TimeoutException のときにリトライする
  );

  print('  result = $result\n');
}
/* 実行結果
  try #1
  try #2
  result = success!
*/
```

ちなみに待機時間が大体どれくらい増えるか確認するには以下で確認ができます。

```dart
  const r = RetryOptions(); // デフォルト設定
  for (var attempt = 1; attempt <= r.maxAttempts - 1; attempt++) {
    final delay = r.delay(attempt);
    print('  attempt #$attempt -> delay = $delay');
  }
  /* 実行結果
    attempt #1 -> delay = 0:00:00.362201
    attempt #2 -> delay = 0:00:00.828308
    attempt #3 -> delay = 0:00:01.402243
    attempt #4 -> delay = 0:00:03.631579
    attempt #5 -> delay = 0:00:06.643290
    attempt #6 -> delay = 0:00:14.554009
    attempt #7 -> delay = 0:00:27.117237
  */
```

## file_testing

https://pub.dev/packages/file_testing

> `package:file` と連携するためのテストユーティリティ。
執筆時のバージョン: **3.0.2**

使えるユーティリティ

- `exists`
  - `FileSystemEntity.existsSync()` が true になるものをマッチ
- `isFile` / `isDirectory` / `isLink` / `isFileSystemEntity` / `isFileStat`
  - それぞれ `File`, `Directory`, `Link`, `FileSystemEntity`, `FileStat` 型かどうかをマッチ
- `hasPath(path)`
  - `entity.path == path` になるかをマッチする Matcher を返す
- `isFileSystemException([osErrorCode])`
  - `FileSystemException` であること（必要なら OS エラーコードも）をチェックする Matcher
- `throwsFileSystemException([osErrorCode])`
  - 「関数 or Future が `FileSystemException` を投げる」ことを検証する Matcher
- `expectFileSystemException(osErrorCode, callback)`
  - `callback` が指定された OS エラーコードを持つ `FileSystemException` を投げることを `expect` 相当でチェックするヘルパー

実際にテストを書いて試してみます。 `pubspec.yaml` は以下の様に設定してまうす。

```yaml
dependencies:
  file: ^7.0.1

dev_dependencies:
  test: ^1.25.6
  file_testing: ^3.0.2

```

`package:file` の `MemoryFileSystem` を使って実ファイルを作らずにテストを書いてみました。

- 実際のテスト

  ```dart
  import 'package:file/file.dart';
  import 'package:file/memory.dart';
  import 'package:file_testing/file_testing.dart';
  import 'package:test/test.dart';
  
  void main() {
    late MemoryFileSystem fs;
  
    setUp(() {
      fs = MemoryFileSystem();
      fs.file('/foo.txt').writeAsStringSync('hello');
      fs.directory('/dir').createSync();
      fs.link('/link-to-foo').createSync('/foo.txt');
    });
  
    group('基本の型系 Matcher', () {
      test('exists / isFile / isDirectory / isLink / isFileSystemEntity', () {
        final file = fs.file('/foo.txt');
        final dir = fs.directory('/dir');
        final link = fs.link('/link-to-foo');
  
        // /foo.txt が存在するファイルである
        expect(file, exists);
        expect(file, isFile);
        expect(file, isFileSystemEntity);
  
        // /dir が存在するディレクトリである
        expect(dir, exists);
        expect(dir, isDirectory);
        expect(dir, isFileSystemEntity);
  
        // /link-to-foo がシンボリックリンク
        expect(link, exists);
        expect(link, isLink);
        expect(link, isFileSystemEntity);
      });
  
      test('isFileStat', () {
        final stat = fs.file('/foo.txt').statSync();
        expect(stat, isFileStat);
      });
  
      test('hasPath', () {
        final file = fs.file('/foo.txt');
        final dir = fs.directory('/dir');
  
        // パスが /foo.txt である File
        expect(file, hasPath('/foo.txt'));
  
        // パスが /dir である Directory
        expect(dir, hasPath('/dir'));
      });
    });
  
    group('FileSystemException 系', () {
      /// 必ず FileSystemException を投げる処理
      void throwNoSuchFile() {
        fs.file('/no/such/file').readAsStringSync();
      }
  
      test('isFileSystemException', () {
        try {
          throwNoSuchFile();
          fail('例外が発生するはず');
        } on FileSystemException catch (e) {
          // FileSystemException であること
          expect(e, isFileSystemException());
        }
      });
  
      test('throwsFileSystemException (関数)', () {
        // コールバックが FileSystemException を投げること
        expect(() => throwNoSuchFile(), throwsFileSystemException());
      });
  
      test('throwsFileSystemException (Future)', () async {
        Future<void> asyncThrow() async {
          throwNoSuchFile();
        }
  
        // Future が FileSystemException で失敗すること
        expect(asyncThrow(), throwsFileSystemException());
      });
  
      test('expectFileSystemException + ErrorCodes.ENOENT', () {
        // こちらは元のままで OK（実際に FileSystemException が投げられるパターン）
        expectFileSystemException(ErrorCodes.ENOENT, () {
          fs.directory('/no/such/dir').resolveSymbolicLinksSync();
        });
      });
    });
  }
  
  ```
