# 概要

本記事では、Ubuntu環境にblogsyncをインストールし、はてなブログとの接続設定から、既存記事の取得、Markdownによる下書き投稿、表示確認、テスト記事の削除までを順番に解説します。

事前にはてなブログのアカウント登録を済ませている前提です。

<!-- 未対応ブロック: link_preview -->

> [blogsync](https://github.com/x-motemen/blogsync)は、はてなブログの記事をローカルのファイルとして取得・編集・投稿できるCLIツールです。記事をMarkdownファイルで管理できるため、普段使っているエディタで執筆したり、Gitで変更履歴を管理したり、自動投稿の仕組みに組み込んだりできます。はてなブログとは[AtomPub API](https://developer.hatena.ne.jp/ja/documents/blog/apis/atom/)を通じて同期します。

# 動作環境

- Ubuntu 26.04 LTS（GNU/Linux 7.0.0-28-generic x86_64）

# 環境構築

## goのインストール

```bash
sudo apt update
sudo apt install -y golang
go version
```

`go version` の表示内容は、インストールされるバージョンや環境によって異なります。

## blogsyncインストール

```bash
go install github.com/x-motemen/blogsync@latest
```

`blogsync` コマンドが見つからない場合は、Goのインストール先をPATHへ追加します。すでに設定済みの場合は不要です。

```bash
echo 'export PATH="$PATH:$HOME/go/bin"' >> ~/.bashrc
source ~/.bashrc
```

最後にコマンドを実行できることを確認します。

```bash
blogsync --help
```

# blogsyncの設定ファイルを作る

今回は `~/workspace/blog` で作業するとして、`~/workspace/blog/blogsync.yaml` に以下内容のyamlファイルを作成します。

```yaml
YOUR_BLOG_ID:
  username: "YOUR_HATENA_ID"
  password: "YOUR_API_KEY"

default:
  local_root: "/home/YOUR_USER/workspace/blog"
```

- `YOUR_BLOG_ID`
  - `example.hatenablog.com` など

  - 「ダッシュボード」>「設定」>「詳細設定」>「AtomPub」で確認できます
    ![](/images/07f601d09fb220/3b2a252da4fa80279b86db77ac2e9f0f.png)

    ![](/images/07f601d09fb220/3b2a252da4fa80f099fbf9c6aec75fa2.png)

- `YOUR_HATENA_ID`
  - はてなID

- `YOUR_API_KEY`
  - はてなのAPIキー

  - 上記「AtomPub」の「アカウントの設定」のページを開いて下にスクロールすると「APIキー」項目があり「発行する」をクリック

  - 投稿用メールアドレスを発行すると、アカウントの設定のAPIキーにキーが表示される

- `/home/YOUR_USER/workspace/blog`
  - 先ほど作成した `~/workspace/blog` を絶対パスで指定

`blogsync.yaml` にはAPIキーが含まれるため、Gitで管理する場合はコミット対象から除外します。

```plain text
blogsync.yaml
```

設定できているか確認するため、以下を実行します（`[YOUR_BLOG_ID]` は設定したブログIDに置き換えてください）。

```bash
blogsync pull [YOUR_BLOG_ID] && echo "blogsyncの接続・認証に成功しました"
```

成功したら「blogsyncの接続・認証に成功しました」と表示され、もし既存記事がある場合は `~/workspace/blog/[YOUR_BLOG_ID]/entry` に保存されます。

# テスト投稿

`~/workspace/blog` に以下内容で `test.md` を作成し下書き(draft)として記事を作成してみます。

- `test.md` (中身は適当です)
  ```markdown
  Ubuntuからblogsyncを使って投稿したテスト記事です。

  ## 動作確認

  以下の処理を確認しています。

  - blogsyncの認証
  - Markdown記事の投稿
  - はてなブログとの同期

  問題なく表示されていればテスト成功です。
  ```

早速投稿してみます。

```bash
blogsync post \
  --draft \
  --title="blogsync 投稿テスト" \
  [YOUR_BLOG_ID] \
  < test.md
```

うまくいけば「記事の管理」>「下書き」に先ほどの記事が保存されています。

![](/images/07f601d09fb220/3b2a252da4fa806ea1aad2136c6c083f.png)

ローカル側にも、以下のようなファイルが作成されているかと思います。

```bash
~/workspace/blog/[YOUR_BLOG_ID]/entry/_draft/記事ID.md
```

## 編集モード

上記の記事をPreviewで開くとマークダウンが反映されていない場合があります。その場合は「設定」>「基本設定」>「記事設定 編集モード」を「Markdownモード」にして保存します。

![](/images/07f601d09fb220/3b2a252da4fa80c4bf33e616850cbca7.png)

再度記事を投稿したらマークダウンが反映された見た目になっているかと思います。

![](/images/07f601d09fb220/3b2a252da4fa80c9b70acff6fb70e560.png)

# 下書き記事を削除

最後にテスト投稿した下書き記事を削除します。

```bash
blogsync remove \
  ~/workspace/blog/[YOUR_BLOG_ID]/entry/_draft/記事ID.md
```

# 記事を公開する場合

記事のヘッダーにある `Draft: true` の部分を `Draft: false` に修正し以下のコマンドを実施します。

```bash
blogsync push  ~/workspace/blog/[YOUR_BLOG_ID]/entry/_draft/記事ID.md
```

# まとめ

Ubuntuへblogsyncを導入することで、はてなブログの記事をローカルのMarkdownファイルとして管理し、コマンドラインから取得・投稿できるようになります。

今回の手順では、blogsyncのインストール、AtomPub APIを利用した認証設定、下書き投稿、Markdown表示の確認、テスト記事の削除までを行いました。

今後は、記事ファイルをGitで管理したり、定期実行ツールと組み合わせて投稿を自動化したりする運用にも応用できます。
